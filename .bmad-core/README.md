# BMAD Method - MemoryCloud

BMAD (Build More, Architect Dreams) Method framework installed for structured development.

## Version
Custom BMAD Core v1.0.0 (manually installed for MemoryCloud project)

## Structure

```
.bmad-core/
├── agents/           # Role-based AI agents
│   ├── analyst.md       # Business Analyst
│   ├── pm.md            # Product Manager
│   ├── architect.md     # Software Architect
│   ├── scrum-master.md  # Scrum Master
│   ├── dev.md           # Developer
│   └── qa.md            # QA Engineer
├── workflows/        # Development workflows
├── templates/        # Document templates
└── README.md         # This file
```

## Agents

### Business Analyst
Requirements gathering, user stories, acceptance criteria

### Product Manager
Product vision, roadmap, backlog prioritization

### Software Architect
System design, technical decisions, architecture documentation

### Scrum Master
Sprint facilitation, impediment removal, process improvement

### Developer
Code implementation, testing, technical excellence

### QA Engineer
Test planning, quality assurance, bug reporting

## Workflow

1. **Analyst** → Gather requirements and write user stories
2. **PM** → Prioritize backlog and plan releases
3. **Architect** → Design technical solution
4. **Scrum Master** → Plan sprint and facilitate execution
5. **Dev** → Implement features and write tests
6. **QA** → Test and verify quality

## Usage

Load the appropriate agent file into your AI coding assistant to adopt that role's perspective and responsibilities.

See `docs/BMAD_SETUP.md` for detailed usage instructions.
